# ADR-005: Low Initial Macro-F1 Acceptance

Status: Accepted

## Context
During Phase 3 evaluation, the tuned KNN model achieved a CV Macro F1 of ~0.655 and a test F1 of ~0.662. This falls below the initial target of 0.80.

## Decision
We accept this performance baseline without altering the underlying synthetic data generator. 

## Rationale
- The **Extreme Error rate is only 0.9%** (well below the 3% threshold), meaning the model almost never confuses a "Low" performer with a "High" performer. The errors are almost entirely adjacent boundaries (Low vs Medium, Medium vs High), which is realistic for subjective appraisal boundaries.
- Synthetic noise parameters intentionally introduced heavy overlap to mirror real-world subjective HR data.
- The model is strictly decision support; 0.66 F1 with high calibration (Brier 0.121) is sufficient for initial alpha testing.

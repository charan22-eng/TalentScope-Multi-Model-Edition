# ADR-001: Stack Decisions

## Status
Accepted

## Context
We need to finalize the technology stack for TalentScope (Explainable Employee Performance Intelligence), a full-stack application that involves Machine Learning, 3D visualizations, and interactive UI, while ensuring it is robust, maintainable, and aligned with modern tooling.

## Decision
- **Data/ML**: Python 3.11+, scikit-learn, imbalanced-learn, joblib. Reusable logic in `ml/src/epk/`.
- **Backend**: FastAPI, Pydantic v2, SQLAlchemy 2, SQLite (local), PyJWT, pytest.
- **Frontend**: React 19 + TypeScript (strict) + Vite, TailwindCSS, shadcn/ui. State managed via Zustand. Recharts for 2D charts.
- **3D/Motion**: React Three Fiber 9.8.1, drei 10.7.9, GSAP + ScrollTrigger, Motion.
- **Quality/DevOps**: Vitest, Playwright, Docker, GitHub Actions.

## Consequences
- React 19.0.0 and R3F 9.8.1 / drei 10.7.9 used, avoiding release candidates and `--legacy-peer-deps`.
- Unified stack allows us to move fast with high quality.

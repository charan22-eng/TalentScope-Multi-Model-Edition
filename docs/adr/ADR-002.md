# ADR-002: Package and Dependency Manager

## Status
Accepted

## Context
We need a fast, reliable package manager for Python to handle dependencies for the ML and backend environments. We want something that supports fast resolution, locking, and isolated environments.

## Decision
We will use **uv**. It is an extremely fast Python package installer and resolver written in Rust. It natively supports creating virtual environments and installing packages from `requirements.txt` or `pyproject.toml`.

## Consequences
- Fast CI/CD times.
- Developer setup is simplified via `Makefile` calling `uv`.

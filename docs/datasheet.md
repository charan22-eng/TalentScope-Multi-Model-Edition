# Datasheet for Employee Performance Synthetic Dataset

## Motivation
- **For what purpose was the dataset created?** To provide a safe, anonymized, and structurally realistic dataset for training a decision-support model (TalentScope) predicting employee performance, avoiding privacy risks of using real PII.
- **Who created it?** Generated by the Phase 1 setup script (`data.py`).

## Composition
- **What do the instances represent?** Each instance represents an employee year-in-review.
- **Are there any errors, sources of noise, or redundancies?** Significant Gaussian and categorical noise was injected to mimic subjective real-world appraisal overlap (macro F1 ~0.66).

## Collection Process
- **How was the data acquired?** Fully synthetically generated (Seed 42).
- **Does the dataset contain data that might be considered sensitive?** No real people are represented. It does contain synthetic job levels and performance reviews.

## Uses
- **Intended Use**: Prototyping explainable AI and testing bias mitigation strategies in a sandbox.
- **Out of Scope**: Training a production model for real-world HR deployment (synthetic boundaries do not transfer to real people).
